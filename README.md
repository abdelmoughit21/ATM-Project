# 🏧 ATM Management System (C++ Console Application)

A simple ATM simulation system built in C++ that allows users to log in, check balance, withdraw money, and deposit funds using a file-based storage system.

---

## 📌 Features

- 🔐 Secure login using account number and PIN code  
- 💸 Quick withdrawal (preset amounts)  
- 💰 Normal withdrawal (custom amount, multiple of 5)  
- ➕ Deposit money  
- 📊 Check account balance  
- 💾 Persistent data storage using text file (`Clients.txt`)  
- 🔄 Auto-update of client data after each transaction  
- 🚪 Logout and re-login functionality  

---

## 🧠 Concepts Used

- File handling (`fstream`)
- Structs in C++
- Vectors
- Enums
- String manipulation
- Basic authentication logic
- Menu-driven programming
- Modular functions design
